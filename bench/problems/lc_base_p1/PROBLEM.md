# Count Primes (easy) — Python 3.13

Return the number of prime numbers strictly less than n.

Signature (in solution.py): def count_primes(n: int) -> int
Constraints: 0 <= n <= 10_000_000. Standard library only.
Examples: count_primes(10) == 4 (2, 3, 5, 7); count_primes(0) == 0; count_primes(1) == 0; count_primes(2) == 0.
